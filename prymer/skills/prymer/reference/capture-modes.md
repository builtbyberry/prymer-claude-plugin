# Capture modes

A channel's capture mode controls how you checkpoint context back to it at the end of a chunk of work. It is resolved live (your default, capped by the channel and workspace) and returned as `capture_mode` in every `get_context_for_injection` payload, alongside a `guidance` field. **Always follow the runtime `guidance` — it reflects the current resolved mode, which can change.**

## Auto

This channel's capture mode is AUTO. When you finish a meaningful chunk of work, checkpoint it to the channel with trigger=agent_auto (on checkpoint or share_session): call checkpoint; if checkpoint is not in your tool list, call capture_context, then share_session with session_id set to the session.id capture_context returned. After checkpointing, offer any decision, standard, or durable fact this conversation produced as a record (promote_context_to_record) — creating a record always needs explicit user intent. Confirm the active channel before acting: use an explicit binding or the exact channel the user named — verbatim. list_channels only lists candidates; never infer the channel from the repo, fuzzy-match a similar name, or carry one over. If it is not explicitly set, ask — even when only one channel is visible. A named channel that does not yet exist is new; never substitute a similarly-named existing one.

## Propose

This channel's capture mode is PROPOSE. At the end of a meaningful chunk of work, ask the user whether to checkpoint it to the channel; if they agree, checkpoint with trigger=user_request (on checkpoint or share_session): call checkpoint; if checkpoint is not in your tool list, call capture_context, then share_session with session_id set to the session.id capture_context returned. Never auto-share. With no human present (headless runs), keep it private. After checkpointing, offer any decision, standard, or durable fact this conversation produced as a record (promote_context_to_record) — creating a record always needs explicit user intent. If it is not explicitly set, ask — even when only one channel is visible. A named channel that does not yet exist is new; never substitute a similarly-named existing one.

## Off
